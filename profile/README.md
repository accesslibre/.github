# International Accessibility Task Force

**From accessibility need to public repo.**

IATF helps associations, groups, and individuals turn real accessibility
needs into public open source projects. Accepted projects are published
under this organization, with copyleft licensing and development happening
in the open.

The public site lives at **<https://iatf.cc>**.

## Repositories

| Repo | Status | What it is |
| ---- | ------ | ---------- |
| [`iatf-webpage`](https://github.com/international-accessibility-task-force/iatf-webpage) | Public | Source of `iatf.cc`: pages, project registry, intake form, governance and transparency content. |
| [`iatf-governance`](https://github.com/international-accessibility-task-force/iatf-governance) | Public | Durable public records: governance changes, chair and election records, decisions, operating costs, redacted request summaries. |
| [`iatf-requests`](https://github.com/international-accessibility-task-force/iatf-requests) | Private | Raw intake from the website form. Filtered, redacted, and summarized before anything moves to the public record. |
| [`iatf-selfie`](https://github.com/international-accessibility-task-force/iatf-selfie) | Archived | Early IATF prototype, kept as a public record. |
| [`iatf-bot`](https://github.com/international-accessibility-task-force/iatf-bot) | Archived | Early Discord automation, kept as a public record. |

Accepted accessibility projects live in their own `iatf-<project-name>`
repositories. See the public registry at <https://iatf.cc/projects/>.

## How to take part

- **Request a project** — if you encounter a real accessibility barrier
  that could be addressed by public open source work, send it through
  <https://iatf.cc/propose/>.
- **Contribute** — pick up issues in any active repository, send pull
  requests, or take on a project as its responsible engineer.
- **Translate** — the source is plain English. Translations are added as
  contributors are available.
- **Test** — try IATF projects with the assistive technology you use and
  report back through the relevant repository.

More detail at <https://iatf.cc/join/>.

## Governance

IATF works in public by default. Project acceptance, archival, repository
ownership, the chair role, and the annual election are all documented at
<https://iatf.cc/governance/>. Public records of decisions, operating
costs, and redacted request summaries live at
<https://iatf.cc/transparency/>.
