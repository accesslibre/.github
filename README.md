# .github

Org-wide community health files for the
[International Accessibility Task Force](https://iatf.cc).

Repositories under the IATF GitHub organization that do not ship their
own copy inherit these defaults:

- [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md)
- [`CONTRIBUTING.md`](./CONTRIBUTING.md)
- [`SECURITY.md`](./SECURITY.md)
- [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE)
- [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md)

Durable governance records (chair, decisions, costs, public request
summaries) live in
[`governance`](https://github.com/accesslibre/governance).
The public website is at <https://iatf.cc>.
